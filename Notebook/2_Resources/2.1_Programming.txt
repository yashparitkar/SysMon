====== 2.1 Programming ======
Created Wednesday 04 December 2024

All the programming resources used for the project.


===== STM32 USB communication without the UART =====
https://controllerstech.com/send-and-receive-data-to-pc-without-uart-stm32-usb-com/
This website shows how to use USB CDC on STM32. 

USB CDC (Communications Device Class): Type of communication device class. Keeps software compatibility with RS232 devices. Hence, easier to have custom data transfer protocol.

===== USB CDC + HID in single code -> =====
https://community.st.com/t5/stm32-mcus/how-to-implement-a-usb-device-composite-in-stm32h5/ta-p/708078
STM32 can be programmed such that it will act as USB CDC device and HID (Human Interface Device) at same time. This will allow using single USB port for both the purposes reducing required number of USB ports on the host.

===== Keyboard key modifiers -> To map keys for shortcuts =====
https://www.instructables.com/STM32-As-HID-USB-Keyboard-STM32-Tutorials/
This website demonstrates implementation of STM32 as a keyboard. This will be adapted to HID function in the USB pair and CDC will be used to read system data.
